# 同步内容生成规则

本规则适用于会写入 `task.md` 或生命周期产物并同步到 Issue 的受控生成端。它只约束模型生成，不解析、改写或阻断手写和外部正文。

- 本地、工作区和临时任务文件引用使用行内代码文本，例如 `analysis.md`、`/workspace/file.md`；不要把它们写成 Markdown 链接。
- 非用户语义的 `@` 文本（例如 `@2x`）使用行内代码文本；真实用户 mention、邮箱地址中的 `@` 和固定发布格式按语义保留。
- 正式的 Issue、PR、commit 和外部链接可以保持 Markdown 链接。
- 不确定时保留普通文本，不猜测链接目标；不要为此引入运行时 Markdown 解析器。

# 文档反模式

审查新增或修改的文档时，文档应描述变更后的当前行为，而不是用历史差异替代当前事实。

## 已删除功能的反向描述

当功能已经删除时，面向当前行为的文档不应继续写“该功能不再存在”或“该能力已被移除”。这类反向描述会让已删除概念继续成为读者必须理解的现行知识。

`不再`、`no longer`、`已被移除`、`removed` 和 `used to` 等词可用于定位候选文本，但命中本身不是 finding。审查者必须结合文档用途和变更上下文判断：

- 当前参考文档、规则和使用说明应直接描述现在支持的行为。
- 迁移指南、变更日志和历史记录可以保留必要的前后差异，但应明确其历史或迁移语境。
- 只有当反向措辞把已删除概念保留为现行知识时，才应登记 finding，并引用准确的文件和行号。

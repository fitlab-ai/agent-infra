# 跨平台风险检视

## 适用范围

当变更触及 OS 分支、路径与大小写、shell/命令、权限、符号链接、换行/编码、信号/进程或平台回退时使用。

若变更同时触及测试文件，且需要表达真实平台守卫或测试运行范围，继续完整读取 `.agents/rules/cross-platform-tests.md`。该二级规则只约束测试运行范围；本文件负责实现层的平台语义。没有测试变更时不加载二级规则。

## 检视问题

- 路径、shell、权限和进程行为是否使用目标平台真实语义。
- 平台回退是否保留一致结果，并区分不支持与运行失败。
- 测试是否在真实支持平台执行，而非用测试体内早返回伪装覆盖。

## 证据要求

记录受影响平台、实现分支和回退路径；涉及测试范围时同时记录二级规则加载证据和 `onPlatforms()` 守卫。

## 常见反例

- 用当前开发平台成功推断所有平台等价。
- 以字符串拼接模拟路径或 shell 行为。
- 为形式完整无条件加载测试守卫规则。

## 无法闭环时

可复现的平台缺陷形成 finding；只能在特定真实平台闭环的事项进入 manual-validation；规则缺失、未加载或未覆盖的实际平台风险记录为 gap，不得用结构 gate 替代语义判断。
